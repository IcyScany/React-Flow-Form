### 任务 2：属性配置面板 (The Settings Panel)

实现点击画布组件，右侧面板即刻更新的交互。

#### 实现步骤

- [ ] 创建 `src/components/Settings/index.tsx`
    - [ ] 从 Store 中获取 `selectedId`
    - [ ] 根据 ID 找到对应的组件对象

- [ ] 核心逻辑
    - [ ] 如果 `selectedId` 为空，显示"请选择组件"提示
    - [ ] 如果不为空，渲染 AntD 表单，包含以下配置项：
        - 标题（Label）
        - 字段名（Name）
        - 占位符（Placeholder）
        - 其他组件特定属性

- [ ] 实现实时同步
    - [ ] 监听属性表单的 `onValuesChange` 事件
    - [ ] 调用 Store 的 `updateComponentProps` 实时更新画布

#### 代码示例

```typescript
// src/components/Settings/index.tsx
const Settings: React.FC = () => {
  const { selectedId, items, updateComponentProps } = useStore();
  const selectedItem = items.find(item => item.id === selectedId);

  if (!selectedItem) {
    return <div>请选择组件</div>;
  }

  return (
    <Form
      onValuesChange={(_, values) => {
        updateComponentProps(selectedId, values);
      }}
    >
      {/* 配置表单项 */}
    </Form>
  );
};
```
